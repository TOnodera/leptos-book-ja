# サーバーとの連携

前のセクションでは、サーバーを使ってページのHTML版を生成し、それをブラウザ上で操作可能にするサーバーサイドレンダリングの過程を説明しました。ここまでは、すべてが「アイソモーフィック」でした。言い換えると、アプリはクライアントとサーバーで「同じ（_iso_）形（_morphe_）」をしていました。

しかし、サーバーにできるのはHTMLのレンダリングだけではありません！ 実際、SQLデータベースの読み書きなど、ブラウザには_できない_多くのことを実行できます。

JavaScriptのフロントエンドアプリを作り慣れているなら、この種のサーバー処理を行うために、何らかのREST APIを呼び出すことに慣れているでしょう。PHP、Python、Ruby（あるいはJava、C#など）でサイトを作り慣れているなら、サーバー側の処理こそが日常的な仕事で、クライアント側の対話性は後回しになりがちでしょう。

Leptosなら両方を実現できます。同じ言語を使い、同じ型を共有できるだけでなく、同じファイル内に記述することさえできます！

このセクションでは、アプリケーションのうちサーバー側に固有の部分を構築する方法を説明します。
