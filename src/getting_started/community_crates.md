# Leptosコミュニティと`leptos-*`クレート

## コミュニティ

Leptosを使った開発に入る前に、最後にひとつお伝えしておきます。まだ参加していなければ、ぜひLeptosの[Discord](https://discord.gg/YdRAhS7eQB)や[GitHub](https://github.com/leptos-rs/leptos)で成長を続けるコミュニティに加わってください。特にDiscordチャンネルはとても活発で親しみやすい場所です。皆さんの参加をお待ちしています！

```admonish note
Leptos Bookを読み進めるなかで、わかりにくい章や説明を見つけた場合は、「docs-and-education」チャンネルで知らせるか、「help」で質問してください。疑問を解消するとともに、ほかの読者のために本書を更新できます。
```

Leptosの学習が進み、「Leptosで○○をするにはどうすればよいのだろう」という疑問が生じたら、Discordの「help」チャンネルで似た質問がないか検索してみてください。もちろん、自分で質問を投稿しても構いません。コミュニティの皆さんはとても協力的で、素早く反応してくれます。

GitHubの「[Discussions](https://github.com/leptos-rs/leptos/discussions)」も、質問をしたりLeptosの最新情報を追ったりするのに適した場所です。

もちろん、Leptosでの開発中にバグを見つけた場合や、機能を要望したい場合（あるいはバグ修正や新機能を提供したい場合）は、[GitHubのIssueトラッカー](https://github.com/leptos-rs/leptos/issues)でIssueを作成してください。


## Leptos-*クレート

コミュニティによって作られたLeptos関連クレートは増え続けており、Leptosプロジェクトでより早く成果を出す助けになります。Leptosを基盤として構築され、コミュニティから提供されているクレートの一覧は、GitHubの[Awesome Leptos](https://github.com/leptos-rs/awesome-leptos)リポジトリで確認できます。

新しく登場した将来有望なLeptos関連クレートを見つけたい場合は、Leptos Discordの「Tools and Libraries」セクションを確認してください。このセクションには、Leptosの`view!`マクロ用フォーマッターを扱う「leptosfmt」チャンネル、ユーティリティライブラリ「leptos-use」のチャンネル、UIコンポーネントライブラリ「thaw-ui」のチャンネルがあります。また、「libraries」チャンネルでは、新しい`leptos-*`クレートが[Awesome Leptos](https://github.com/leptos-rs/awesome-leptos)上のクレートやリソースの一覧に加わる前に議論されています。
