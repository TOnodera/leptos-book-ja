# デプロイ

Webアプリケーションのデプロイ方法は、アプリケーションの数どころか、開発者の数だけあります。それでも、アプリをデプロイするときに覚えておくと役立つヒントがいくつかあります。

## 一般的な助言

1. Rustアプリはデバッグモードではなく、必ず `--release` モードでビルドしてデプロイしてください。性能とバイナリサイズの両方に非常に大きく影響します。
2. ローカルでもリリースモードでテストしてください。フレームワークはリリースモードで、デバッグモードには適用しない最適化を行うため、この時点でバグが表面化する可能性があります。（アプリの挙動が異なる、またはバグに遭遇した場合は、フレームワークレベルのバグである可能性が高いため、再現例を添えてGitHub issueを作成してください。）
3. WASMアプリの初回読み込み時に操作可能になるまでの時間をさらに改善するためのヒントやテクニックは、「WASMバイナリサイズの最適化」の章を参照してください。
