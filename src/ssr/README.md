# Part 2：サーバーサイドレンダリング

前章で説明したとおり、クライアントサイドレンダリングにはいくつかの制約があります。本書の
第2部では、サーバーサイドレンダリングでそれらを克服し、Leptosアプリケーションの性能と
SEOを最大限に高める方法を説明します。


```admonish info

Leptosをサーバー側で使う場合、公式対応のActixまたはAxum統合や、コミュニティ対応の選択肢を
自由に選べます。公式統合ではLeptosの全機能を利用できますが、コミュニティ版は対応範囲が
狭い場合があります。詳しくは各ドキュメントを確認してください。

DenoやCloudflareなどのWinterCG互換ランタイム、Spinなどのサーバー側WASMランタイムを含む
多様なコミュニティ対応版があります。VizやPavex向け統合は、より伝統的なサーバーを選べます。
初心者が独自統合を書くことは推奨しませんが、中上級のRust利用者なら挑戦できます。質問は
DiscordまたはGitHubでお問い合わせください。

初心者にはAxumまたはActixを推奨します。どちらも完全に機能し、選択は好みの問題です。
迷った場合、Leptosチームは現在、新規プロジェクトでAxumをデフォルトにしています。
```
