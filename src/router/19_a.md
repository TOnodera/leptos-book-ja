# `<A/>`コンポーネント

クライアント側ナビゲーションは通常のHTML `<a>` 要素でも正しく動作します。Routerは
`<a>` 要素の各クリックを処理するリスナーを追加し、HTMLを要求するためにサーバーと再度
往復せず、クライアント側で処理しようとします。これにより、現代的なウェブアプリケーションで
おなじみの軽快な「シングルページアプリケーション」のナビゲーションが実現されます。

次の状況では、Routerは `<a>` のクリック処理を行いません。

- クリックイベントで `prevent_default()` が呼び出された場合
- クリック時に<kbd>Meta</kbd>、<kbd>Alt</kbd>、<kbd>Ctrl</kbd>、<kbd>Shift</kbd>キーが押されていた場合
- `<a>` に `target`、`download` 属性、または `rel="external"` がある場合
- リンクのオリジンが現在のlocationと異なる場合

つまりRouterは、処理できる可能性が十分高い場合にだけクライアント側ナビゲーションを試み、
すべての `<a>` 要素へこの特別な動作を追加します。

> クライアント側ルーティングを無効にするのも簡単です。同じドメインにありながらLeptos
> アプリケーションの一部ではないページへのリンクには、`<a rel="external">` を使い、
> Routerでは処理できないことを伝えます。

Routerは、さらに2つの処理を行う [`<A>`](https://docs.rs/leptos_router/latest/leptos_router/components/fn.A.html)
コンポーネントも提供します。

1. 相対的なネストRouteを正しく解決します。通常の `<a>` タグによる相対ルーティングは複雑です。`/post/:id` のようなRouteでは、`<A href="1">` は正しい相対Routeを生成しますが、`<a href="1">` はビュー内の位置によって正しく生成しない可能性があります。`<A/>` は、それが置かれたネストRouteのパスを基準に解決します。
2. リンクが現在のページを指すアクティブリンクなら、`aria-current` 属性を `page` に設定します。アクセシビリティとスタイル指定に役立ちます。たとえば現在のページへのリンクだけ色を変える場合、CSSセレクターでこの属性に一致させられます。

## プログラムから移動する

ページ間の移動には主に `<a>` と `<form>` 要素、または拡張版の `<A/>` と `<Form/>`
コンポーネントを使うべきです。リンクとフォームによる移動は、アクセシビリティと
グレースフルデグラデーションに最適です。

ただし、新しいページへ移動する関数を呼び出し、プログラムから移動したい場合もあります。
その場合は [`use_navigate`](https://docs.rs/leptos_router/latest/leptos_router/hooks/fn.use_navigate.html)
関数を使います。

```rust
let navigate = leptos_router::hooks::use_navigate();
navigate("/somewhere", Default::default());
```

> `<button on:click=move |_| navigate(/* ... */)>` のようなコードは、ほぼ使うべきでは
> ありません。アクセシビリティ上、移動を行う `on:click` は `<a>` にするべきです。

第2引数は [`NavigateOptions`](https://docs.rs/leptos_router/latest/leptos_router/struct.NavigateOptions.html)
です。`<A/>` と同様に現在のRouteを基準として移動先を解決する、ナビゲーションスタック上の
項目を置き換える、ナビゲーション状態を含める、移動時に現在のスクロール状態を維持する、
といったオプションがあります。

> 今回も同じ例です。相対的な `<A/>` コンポーネントと、ARIAに基づくスタイルを確認するため
> `index.html` のCSSをご覧ください。

```rust
use leptos::prelude::*;
use leptos_router::components::{Outlet, ParentRoute, Route, Router, Routes, A};
use leptos_router::hooks::use_params_map;
use leptos_router::path;

#[component]
pub fn App() -> impl IntoView {
    view! {
        <Router>
            <h1>"Contact App"</h1>
            // この<nav>は<Routes/>の外側にあるため、すべてのRouteで表示される
            // 通常の<a>タグを使うだけで、Routerがクライアント側ナビゲーションを行う
            <nav>
                <a href="/">"Home"</a>
                <a href="/contacts">"Contacts"</a>
            </nav>
            <main>
                <Routes fallback=|| "Not found.">
                    // /にはネストされていない「Home」だけがある
                    <Route path=path!("/") view=|| view! {
                        <h3>"Home"</h3>
                    }/>
                    // /contactsにはネストしたRouteがある
                    <ParentRoute
                        path=path!("/contacts")
                        view=ContactList
                      >
                        // idが指定されていなければfallbackを表示する
                        <ParentRoute path=path!(":id") view=ContactInfo>
                            <Route path=path!("") view=|| view! {
                                <div class="tab">
                                    "(Contact Info)"
                                </div>
                            }/>
                            <Route path=path!("conversations") view=|| view! {
                                <div class="tab">
                                    "(Conversations)"
                                </div>
                            }/>
                        </ParentRoute>
                        // idが指定されていなければfallbackを表示する
                        <Route path=path!("") view=|| view! {
                            <div class="select-user">
                                "Select a user to view contact info."
                            </div>
                        }/>
                    </ParentRoute>
                </Routes>
            </main>
        </Router>
    }
}

#[component]
fn ContactList() -> impl IntoView {
    view! {
        <div class="contact-list">
            // 連絡先一覧コンポーネント本体
            <h3>"Contacts"</h3>
            <div class="contact-list-contacts">
                <A href="alice">"Alice"</A>
                <A href="bob">"Bob"</A>
                <A href="steve">"Steve"</A>
            </div>

            // <Outlet/>はネストした子Routeを表示し、レイアウト内の任意の場所へ配置できる
            <Outlet/>
        </div>
    }
}

#[component]
fn ContactInfo() -> impl IntoView {
    // `use_params_map`で:idパラメーターへリアクティブにアクセスできる
    let params = use_params_map();
    let id = move || params.read().get("id").unwrap_or_default();

    // ここでAPIからデータを読み込むものとする
    let name = move || match id().as_str() {
        "alice" => "Alice",
        "bob" => "Bob",
        "steve" => "Steve",
        _ => "User not found.",
    };

    view! {
        <h4>{name}</h4>
        <div class="contact-info">
            <div class="tabs">
                <A href="" exact=true>"Contact Info"</A>
                <A href="conversations">"Conversations"</A>
            </div>

            // この<Outlet/>は/contacts/:id Routeの下へネストされたタブ
            <Outlet/>
        </div>
    }
}

fn main() {
    leptos::mount::mount_to_body(App)
}
```
