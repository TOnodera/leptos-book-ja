# `async`を扱う

ここまでは同期的なユーザーインターフェイスだけを扱ってきました。入力を与えると、
アプリケーションがすぐに処理してインターフェイスを更新します。これは便利ですが、
ウェブアプリケーションが行う処理のごく一部にすぎません。特に、ほとんどのウェブ
アプリケーションは、通常APIから何かを読み込む非同期データ読み込みを扱う必要があります。

非同期データは「関数の色付け」と呼ばれる問題により、コードの同期部分との統合が難しいことで
知られています。

以降では、非同期データを扱うリアクティブプリミティブをいくつか見ていきます。ただし最初に
重要な点があります。単に非同期処理を行いたいだけなら、Leptosは `Future` を簡単に実行できる
クロスプラットフォームの [`spawn_local`](https://docs.rs/leptos/latest/leptos/task/fn.spawn_local.html)
関数を提供しています。この節で説明するプリミティブが目的に合わない場合は、`spawn_local` と
シグナルの設定を組み合わせることを検討してください。

これから紹介するプリミティブは非常に便利で、ときには不可欠です。しかし実際には、タスクを
起動して完了を待ち、その後に別の処理を行うだけでよい場合もあります。そのような状況では
`spawn_local` を使ってください！
